# Java Interview Prep

A study reference site for Java and Spring Boot interview preparation.

## Live site

https://java-interview-prep-blush.vercel.app

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
npx serve
```

## Deployment

The site is a static `index.html` deployed on [Vercel](https://vercel.com/). Pushes to the main branch trigger an automatic deployment.
